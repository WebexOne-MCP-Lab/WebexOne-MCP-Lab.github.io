# Take-Home Skill Bundle

After the lab, the team will post the reusable **skill bundle** in the session Webex space. You can download it there and adapt it to your own approved environment. You do not need to export the pod's workspace during the lab.

## What the bundle covers

The skills used in the lab are `meeting-follow-up`, `meeting-quality`, `approval-gate`, `incident-mode`, `attendance-report`, and `multilingual-output`, with their supporting reference files. The bundle is meant to show how to turn repeated agent and MCP work into a reusable workflow.

The lab's separate [quality-tool source]({{config.extra.quality_tool_url}}){:target="_blank"} is available for learning how a local MCP server can wrap a REST API. Bring your own Webex organization, authorization, and tokens when using these examples after the event.

## What the shared files do not include

- Lab passwords, API keys, or personal access tokens
- Meeting transcripts, recordings, or quality telemetry
- Pod-specific organization IDs or member email addresses

Before using a skill in your organization, review its tool permissions, data handling, approval steps, and output format. Control Hub policy and your own approval process remain authoritative.

If the bundle has not appeared after the session, ask the lab team in the same Webex space.
