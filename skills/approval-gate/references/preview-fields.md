# Approval Gate — Required Preview Fields

Before each write action, show the user:

- **Action type** — create space, add member, post message, upload file, schedule meeting, create webhook
- **Target** — space, meeting, file, or webhook being affected
- **Meeting ID and source date** — the meeting the data originates from
- **Recipients or members** — who will receive or be added
- **Exact message or file description** — the content that will be posted or uploaded
- **Meeting date, time, timezone, duration, and invitees** — when scheduling a meeting
- **Data sensitivity and redactions** — any restricted or redacted fields
