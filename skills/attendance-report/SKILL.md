# Attendance Report

Produce a factual attendance report from authorized meeting data. Use `not available` rather than inference. Attendance duration is not proof of attention, contribution, or comprehension.

Minimize fields, restrict recipients, and request approval before posting or attaching the report.

For default columns and formatting details, see [references/default-fields.md](references/default-fields.md).

## Customization

Customers may change columns, output format, neutral labels, and retention language. Do not add unsupported engagement claims.
