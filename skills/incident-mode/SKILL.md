# Incident Mode

Create a restricted Webex coordination space for an approved meeting-quality incident. Present the quality report, obtain approval, create the incident space, and manage updates through closure.

Do not post full participant quality records to a broad space by default.

For the full step-by-step workflow, see [references/workflow.md](references/workflow.md).

## Customization

Customers may customize naming, responder roles, update format, severity mapping, and closure template. Approval and restricted sharing remain mandatory.
