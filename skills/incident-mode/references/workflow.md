# Incident Mode — Workflow

1. Present the quality report and proposed responders.
2. Obtain explicit approval for the space, members, and first message.
3. Create `INCIDENT — <meeting title> — <date>`.
4. Add only approved responders.
5. Post a concise summary with timestamped evidence and recommended checks.
6. Add updates as timestamped replies; preserve the original evidence.
7. Close with resolution, remaining data gaps, and follow-up owner.
