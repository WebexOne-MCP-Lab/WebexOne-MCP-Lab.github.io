# Meeting Follow-Up Output Format

## Default sections

- **Meeting reference** — title, ID, date, and duration
- **Summary** — concise overview of the meeting
- **Decisions** — agreed outcomes with evidence timestamps
- **Action items** — owner, description, due date, and evidence reference
- **Open questions** — unresolved items flagged during the meeting
- **Follow-up meeting proposal** — suggested date, agenda, and attendees
- **Attendance report reference** — link to the attendance report when available

## Formatting notes

- Use bullet lists for action items when posting to a Webex space. Put each owner name in bold; Webex does not render Markdown tables reliably.
- Mark unassigned owners as `unassigned` and missing dates as `not specified`.
- Include evidence timestamps beside each decision and action item.
