# Meeting Follow-Up Workflow

1. Resolve the meeting by topic or date and confirm the selected meeting ID.
2. Retrieve the transcript or summary using the Webex Meetings MCP server.
3. Extract the summary, decisions, action items, owners, due dates, and evidence timestamps.
4. Mark missing or ambiguous owners and dates as `unassigned` or `not specified`.
5. Load the translation and attendance skills only when requested.
6. Produce a draft before any write action.
7. Load and follow the approval gate skill.
8. After approval, create the approved space, add approved members, and post the approved recap.
9. Read the posted message back and return the space and message IDs.
