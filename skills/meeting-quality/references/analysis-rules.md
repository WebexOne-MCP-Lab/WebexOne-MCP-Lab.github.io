# Meeting Quality — Analysis Rules

1. Use the Webex Meetings MCP server to resolve the meeting ID and authorized meeting context.
2. Use the custom quality tool for media-quality telemetry; do not claim MCP returned quality metrics.
3. Separate observations, hypotheses, recommendations, and data gaps.
4. Cite the source field or timestamp for each observation.
5. Do not infer root cause from a single metric.
6. Treat participant-level data as restricted.
7. Require approval before creating an incident space or posting quality details.
