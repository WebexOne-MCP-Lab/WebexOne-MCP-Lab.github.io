# Multilingual Output

Create reviewed multilingual follow-up content without changing source facts. Require approval before posting each language version.

For detailed translation rules and preservation requirements, see [references/translation-rules.md](references/translation-rules.md).

## Customization

Customers may define supported languages, terminology glossaries, bilingual layout, and translation confidence labels. They may not remove source preservation or approval.
