# Multilingual Output — Translation Rules

## Process

1. Ask for the target language or languages.
2. Translate the meeting content while applying the preservation rules below.
3. Keep the source-language text available beside the translation when requested.
4. Flag uncertain translations and technical terms.
5. Require approval before posting each language version.

## Preservation rules

The following must remain exactly as they appear in the source:

- **Names** — participant and organization names
- **Meeting IDs** — numeric or alphanumeric identifiers
- **Dates and times** — timestamps, due dates, calendar references
- **URLs** — links to resources, recordings, or documents
- **Code and commands** — CLI commands, API paths, code snippets
- **Email addresses** — contact addresses

## Restrictions

- Do not translate or publish secrets, tokens, or credentials.
- Do not alter numeric values, currency amounts, or units of measure.
